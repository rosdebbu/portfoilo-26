# portfoilo-26

Personal portfolio of **Debjit Das** — Full-Stack, AI & CFD Engineer (B.Tech CSE Data Science @ SRMIST, NASA Space Apps Chennai 3rd Place).

## Features
- **Interactive WebGL Hero** with 4 live GLSL image simulation modes (`Bayer Dither`, `Fluid CFD`, `Halftone`, `Studio Clean`)
- **Interactive CFD & Topology Lab** with real-time Reynolds number (`Re`) & inflow velocity (`U∞`) controls, Kármán vortex street, and NACA Airfoil / Cylinder boundary bodies
- **Scroll-Choreographed Spotlight Chapters** powered by Lenis & GSAP ScrollTrigger
- **Dual-Mode Work Archive** (cursor-tracking List Preview + filterable Gallery Grid + 3-column Detail Modal)
- **Editorial About & Curved Footer** with live IST clock and magnetic interactions

## Tech Stack
React 19 · TypeScript · Tailwind CSS v4 · Three.js (GLSL) · GSAP · Lenis · Vite
